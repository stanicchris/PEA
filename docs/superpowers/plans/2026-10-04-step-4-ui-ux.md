# Plan d'implémentation - Étape 4 : UI/UX Avancée (Mode Discret & ⌘K)

## Contexte
Ce plan couvre la **Phase 4** de la refonte du dashboard PEA.
Puisque le nouveau plan du site (Routeur) a déjà été implémenté en Phase 2, cette phase se concentre sur les fonctionnalités transversales d'expérience utilisateur (UX) très demandées.

## Étapes

### Tâche 1 : Mode Discret (Confidentialité)
- **Objectif** : Permettre à l'utilisateur de masquer les montants en euros (remplacés par des astérisques `*** €`) pour ouvrir l'app en public ou partager des captures d'écran, tout en gardant les pourcentages visibles.
- **Détails** :
  - Ajouter un état `isDiscreteMode` dans le store Pinia (`src/stores/app.js`).
  - L'activer/désactiver via le menu profil ou un raccourci clavier.
  - Sauvegarder la préférence dans `localStorage`.
  - Mettre à jour `HeroSection.vue` et `FiscalStackCard.vue` pour utiliser ce mode.

### Tâche 2 : Palette de commandes (Raccourci ⌘K)
- **Objectif** : Remplacer la simple barre de recherche par une vraie "Command Palette" (façon Spotlight ou Raycast) accessible via ⌘K ou Ctrl+K.
- **Détails** :
  - Créer un composant `CommandPalette.vue`.
  - Capturer l'événement clavier global (`Cmd+K` ou `Ctrl+K`).
  - Permettre de chercher des actions (pour ouvrir `AssetInspectorModal`) et de naviguer entre les pages du routeur.

### Tâche 3 : Support PWA (Progressive Web App)
- **Objectif** : Rendre l'application installable sur mobile et desktop.
- **Détails** :
  - Ajouter `vite-plugin-pwa` ou configurer un simple `manifest.json` avec les icônes existantes.
  - S'assurer que le rendu sur mobile est parfait.
